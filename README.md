# EbenézerConecta

Plataforma de relacionamento com doadores do Instituto Social Ebenézer — MVP da Semana 10 (MBA em IA e Dados para Negócios, Inteli, Módulo 3).

Este repositório está em construção. A estrutura final:

- `supabase/` — migrations, seed sintético, views, funções e testes do banco (Postgres + RLS)
- `web/` — front-end Next.js, sem regra de negócio, fiel ao protótipo em Figma
- `docs/` — modelo de dados, operação, decisões técnicas e custos
